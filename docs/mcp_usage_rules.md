# MCP Usage Rules & Boundaries

## MCP Default Policy
- **Read-only**: Actions are strictly read-only unless the user explicitly commands a modification.
- **MCP Priority**: Use MCP tools whenever available before falling back to shell or script workarounds.
- **Untrusted Output**: All output generated by MCP tools is treated as untrusted. Local execution gates must pass before committing or pushing any MCP-generated changes.

## Filesystem MCP Boundary
- The filesystem MCP is restricted to operate **ONLY** within `C:/Users/eltun/Documents`.
- **Do not access** any paths outside of `C:/Users/eltun/Documents` via the filesystem MCP.

## Shell Fallback Policy
- Do not use shell commands (e.g., PowerShell, bash) unless the designated MCP tool cannot perform the required task.
- If a shell is used, strictly obey the safe execution policies defined in the repository.

## Secrets/API Keys Policy
- **Never** expose, print, log, or commit tokens, API keys, or sensitive credentials. 

## DB Safety Policy
- `production.db`, private DB backups, secrets, and ignored artifacts **must not** be exposed or fed into MCP tools.
- Any DB-adjacent tasks (like validation, querying) must be executed using local read-only Python/PowerShell scripts safeguarded by git hooks and mutation guards.

## GitHub MCP Policy
- Use GitHub MCP strictly in **Read-only** mode. 
- Do not modify files, branches, issues, PRs, releases, workflows, or repository settings using GitHub MCP.

## Markitdown MCP Policy
- Use Markitdown MCP for safe read-only parsing of markdown content when required, without altering the underlying files.

## Failure Mode
- If Docker or an MCP server is unavailable, the workflow does not stop. Fall back to the standard local Git/PowerShell workflow and run local gate scripts.

## Task Lifecycle (Before/After MCP)
Every task involving MCP interactions must be wrapped with local integrity checks:

**Before MCP-assisted task:**
```powershell
git status --short
powershell -ExecutionPolicy Bypass -File scripts/gates/run_all_gates.ps1
```

**After MCP-assisted task:**
```powershell
git status --short
powershell -ExecutionPolicy Bypass -File scripts/gates/run_all_gates.ps1
```
