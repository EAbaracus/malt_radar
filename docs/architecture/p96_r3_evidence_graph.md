# P96-R3 Evidence Graph & Explainability Layer

## 1. Overview
P96-R3 introduces an explicit Evidence Layer to the Knowledge Engineering Pipeline. The system is no longer simply mapping chunks to facts; it now generates immutable, first-class Evidence nodes that stand between the citation layer (books/pages) and the extracted facts. 

This model ensures complete transparency for future Reducer stages (e.g., D4). Any canonical assertion generated by Malt Radar can be traced backwards to reveal the exact consensus rationale, the supporting/conflicting evidence weights, and the original quoted text.

## 2. Evidence Model
Each Evidence record is generated deterministically and represents a single atomic assertion. It is strictly immutable.
```json
{
  "evidence_id": "EV-999-ABC",
  "citation_id": "chunk999",
  "book_id": "BK_JACKSON_01",
  "page": 142,
  "paragraph": 2,
  "sentence": 3,
  "quoted_text": "intense medicinal peat",
  "extracted_value": {"descriptor": "Peat", "category": "Palate"},
  "extraction_method": "llm_schema",
  "extraction_confidence": 0.99,
  "model_identifier": "gemini-1.5-pro",
  "prompt_version": "v1.0",
  "schema_version": "v2.1"
}
```

## 3. Evidence Graph Architecture
The graph maps the transition from raw document to canonical descriptor via explicit node connections:
- `Book` (e.g. BK_JACKSON_01) 
  - `HAS_CITATION` -> `Citation` (e.g. chunk999) 
    - `PROVIDES_EVIDENCE` -> `Evidence` (e.g. EV-999-ABC)
      - `SUPPORTS_FACT` -> `Extracted Fact` (e.g. Palate: Peat)
        - `MERGED_INTO` -> `Consensus` (e.g. Weighted Peat Consensus)
          - `APPLIES_TO` -> `Whisky Entity` (e.g. Lagavulin 16)
          - `RESOLVES_TO` -> `Descriptor / Canonical Axis`

## 4. Consensus Explainability
The Consensus Node acts as the focal point for conflict resolution. It retains a complete ledger of its decision rationale:
- `supporting_evidence`: Array of `evidence_id`s that agree.
- `conflicting_evidence`: Array of `evidence_id`s that disagree or provide minority opinions.
- `evidence_weights`: Calculated based on authority tier and extraction confidence. (T3 data is never artificially elevated).
- `consensus_rationale`: Deterministic text detailing why the consensus was chosen.

## 5. D4 Reducer Explainability
While D4 (NotebookLM/Book Promotion) is explicitly deferred, this architecture prepares for it. A user or auditor clicking on a Canonical Axis (e.g., "Smoke = High") on the frontend will trace the graph backwards:
Canonical Axis <- Consensus <- Evidence <- Citation <- Book, revealing the precise sentence used to make the determination.

## 6. Migration from P96-R2
- R2 generated `Extracted Fact` nodes directly linked to `Citation` metadata.
- R3 decouples these by inserting the immutable `Evidence` node, separating the *source claim* from the *normalized fact*.
- No data is migrated; staging continues unaffected.
