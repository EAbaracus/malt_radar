## 2025-02-14 - Fix Timing Attack Vulnerability in Token Comparisons
**Vulnerability:** Security-sensitive API keys and tokens were being compared using standard Python string equality operators (`!=`, `==`), which evaluates character-by-character and fails fast. This allowed for timing attacks where an attacker could deduce tokens by measuring small timing differences.
**Learning:** In Python, standard string comparison is vulnerable to timing attacks when verifying security credentials (like API keys, verification proofs, or hashes). The `secrets.compare_digest` method evaluates strings in constant time regardless of where they differ, mitigating this attack surface.
**Prevention:** Always use `secrets.compare_digest(a, b)` for comparing API keys, auth tokens, cryptographic proofs, or password hashes. Note that `compare_digest` can raise a `TypeError` if given `None`, so `None` checks must be explicitly handled beforehand (e.g. `if not val or not secrets.compare_digest(...)`).
