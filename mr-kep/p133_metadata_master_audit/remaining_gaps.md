# Remaining Gaps

Even after fully exploiting the current corpus, the following data points will remain absent:

### 1. Completely Unsolvable (Requires External API)
- **Live Prices:** Book data is historical. Real-time pricing requires active web scraping or API integrations.
- **Images:** No image binary files exist in the current library.

### 2. Partially Solvable
- **Finish Types:** Standard standard-range whiskeys rarely list finish types in books unless they are double-matured.
- **Independent Bottler details:** Most books focus entirely on Official Bottlings (OB), leaving independent single-cask data (aside from SMWS) very thin.
