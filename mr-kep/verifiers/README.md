# MR-KEP Sprint 2 Unified Verification Framework

This directory contains the universal verification tooling for all Sprint 2 components (Qualification Engine, Evidence Engine, Execution Engine, etc.).

## Purpose

The verifier strictly audits implementation code (`.py`, `.yaml`, `.json`) while completely ignoring documentation and prose. This ensures no false positives are generated by markdown discussions of rules like "No OCR" or "No AI".

## Checks Performed

1. **Determinism:** Rejects stochastic logic (e.g., `import random`) and non-deterministic UUIDs (`uuid.uuid4`).
2. **Safety:** Rejects any `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, or `VACUUM` against `production.db`.
3. **No OCR:** Rejects OCR libraries (e.g., `pytesseract`, `easyocr`).
4. **No AI:** Rejects AI/LLM libraries (e.g., `openai`, `transformers`, `langchain`).
5. **No Scraping:** Rejects scraping libraries (e.g., `requests`, `selenium`, `scrapy`).
6. **No External Network:** Rejects HTTP requests and API calls.
7. **Schema Compatibility:** Confirms no Sprint 1 schemas are redefined.
8. **P64 Compatibility:** Evidence ID formats and ledger structure compatibility.
9. **P65 Compatibility:** Canonical output compatibility.
10. **P67 Compatibility:** Qualification contracts unchanged.
11. **P68 Compatibility:** Execution lifecycle contracts unchanged.

## Usage

```bash
python mr-kep/verifiers/verify_sprint2.py
```

This will output a `verification_report.md` detailing the pass/fail status of all checks.
