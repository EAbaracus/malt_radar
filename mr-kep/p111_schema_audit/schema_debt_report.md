# Schema Technical Debt Report

## Current State of `whiskies`
The `whiskies` table lacks constraints, explicit types, and primary keys. The schema signature heavily implies it was auto-generated by an ORM or a loose data import tool (such as Pandas `DataFrame.to_sql()`) during the project's inception.
- No `PRIMARY KEY` on `whisky_id`.
- No `UNIQUE` constraints.
- No indexes of any kind exist on the table.

## Dependent Tables
The following tables correctly define standard SQLite foreign keys pointing to `whiskies(whisky_id)`:
- `price_history`
- `staging_web_tasting_notes`

## Debt Origin
The mismatch was **not caused by a recent migration**. The defective `whiskies` schema has existed since its initial creation. The debt became visible only when later tables (`price_history`, `staging_web_tasting_notes`) were properly engineered with explicit `FOREIGN KEY` constraints pointing back to the legacy schema, creating a structural mismatch in SQLite's enforcement engine.
