# Timing Analysis

## How 803 PDFs were processed in 0.78 seconds:
The extremely fast processing time is because the deterministic extractor in Phase 2 did **NOT** perform physical file parsing or OCR on the original PDF binary files. Instead, it read the pre-extracted JSONL file (`smws_raw_records.jsonl`) generated by the Phase 1 script (which originally took several minutes). The Python pipeline only executed regex matching in memory, completely eliminating I/O bottlenecks and PDF rendering overhead.
