# Change Workflow

1. **Read AGENTS.md:** Always review core instructions before any change.
2. **Read Affected Rules:** Locate and read any relevant rules in `rules/`.
3. **Identify Impacted Files:** Trace imports, database connections, and side-effects.
4. **Produce Change Plan:** Draft the refactoring or implementation plan.
5. **Apply Minimal Change:** Prefer small, targeted diffs. Do not add bloat.
6. **Validate:** Verify execution, run integrity checks, and check data statistics.
7. **Review Git Diff:** Verify all deletions/renames/modifications before commit.
8. **Report:** Output a formal walkthrough or verification report.
